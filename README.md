# FallBall 2026

> Single-file web app for managing the SBSL Fall 2026 softball team — roster, lineups, game stats, pitching, and play-time compliance.

## Business Problem

Coaches needed a shared, real-time tool to track which players have batted, manage fielding rotations, and stay compliant with the league's minimum play-time rules — without spreadsheets or paper.

## Why

Built for the SBSL Fall 2026 season. Without it, coaches track compliance by hand and have no shared view of lineup history across games.

## How

Single `index.html` backed by Firebase Firestore for real-time sync across coach devices. Hosted on GitHub Pages with no build step — coaches open the URL and the app is live.

## Not This

Not a live scorekeeping app during a game. Not a parent-facing portal or communication tool. Not a tournament bracket manager. Does not integrate with GameChanger or any external league platform.
